# 进展速记

## 本期假设 / 预期

**预期：**

这期的核心是补充支线任务，如果可以的话再补些 lore 网站

**结果：**

实际上全用在现有 lore 优化上了……

## 本期确定性变化

### 新增：

- 在茶馆网站上添加了一个和网站上的广告相关的帖子，玩家可以从中了解到空间站管理系统的官方网站，也能从中侧面了解到空间站的管理体系。用点心还能看到一个乐子小故事
- 补充了茶馆网站上的一个关键角色的相关帖子，增强世界观风味、有助于玩家侧面了解到审计部在游戏世界中的地位

### 变更：

- 优化了游戏时间推进过程的演出
  - 之前单独遮罩主窗口，会让主窗口里的基于 webview 子窗口的 terminal 无法被正确遮罩，而且也没法阻止玩家操作其他窗口的内容
  - 改成了全屏遮罩（期间还遇到了一个十分抽象的 bug，最后发现是因为 [https://github.com/godotengine/godot/issues/107582](https://github.com/godotengine/godot/issues/107582)）
- 优化了 carrier 界面，现在更加易用了，完成度看起来也更高
- 优化了居住区 poi 的前端，完成度看起来会更高
- 优化了 godot 和网页的事件机制，现在可以彻底和轮询说再见了
- 重做了被注入脚本内部实现的 lore，现在没有诸如“游戏时间”之类的破坏沉浸感的表述了
- 优化了论坛架构
  - 现在论坛和任务板使用相同的底层逻辑了
  - 将本来只用于任务板的以“回复”为粒度的解锁机制合入了通用论坛架构
  - 有更新的帖子显示会更靠上
- 优化了论坛网友昵称的英文翻译

### 修复：

- 修复了论坛发帖时间总是显示“刚刚”的 bug

# 主要进展内容/本期关键判断点

> 我做出了哪些「如果错了也要付代价」的判断？

## zcode……

zcode 为什么会犯把英文引号写成中文引号的低级错误……这 tmd deepseek 都不会犯的啊

但 codex 反而在 ChatGPT 6 的加持下变得十分好用……一切战术转换家是吧

## 关于叙事设计

之前我有些陷入误区了，觉得和世界观无关的叙事都是冗余的、可能让玩家觉得作者在自嗨的负面资产。但是在这期的 lore 优化中，我觉得关键是只要叙事有意思，那不管是否和世界观相关玩家应该都会对此感兴趣。

同时相应的，我也给一些原本和世界观叙事有强烈联系但不是很有意思的内容做了优化，提高了相关趣味性——毕竟反过来说，只要叙事没意思，不管是否和世界观相关玩家可能都会不感兴趣

# 瓶颈与问题清单

> 哪些问题还没解，但也许我已经知道“它们不是什么”？

- AI 美术已经能稳定生产 ProxyOS 所需的单视角素材，但一致三视图仍无可靠方案。
  - 这个研究了一下，要真正稳定生成的话要么定制模型，要么先生成 3d 模型然后由 2d 模型对着指定角度截图进行重绘——而不管哪个都不是我这个 7G 显存的电脑能搞定的。至于在线服务……全都在堆人型特化，rimworld 这种风格化的完全用不了
- Zcode 当前上下文管理和工程纪律明显退化，短期需要重新评估辅助编码模型组合。
  - 上期说想试试 kimi 来着，结果了解后发现吞吐量和完成任务所需的 token 数都颇为灾难，所以放弃了。至于剩下的选项……
    - zcode 脑瘫了
    - dsh 能力不确定能不能胜过脑瘫后的 zcode，而且 deepseek 的峰谷基本是整个白天都是高峰，价格优势也不明显
    - Qoder 比 kimi 还灾难
    - claude code 被 A/的封号整得没法用
    - codex 涨价了（pro 还是$200 但配额只有一半了，额度单价和 plus 没区别了）
  - 竟然没有一个更好的替代的耶！
- mod 元信息、依赖、锁文件和版本回滚仍需形成稳定流程。
- 也许加载性能还能优化一下
