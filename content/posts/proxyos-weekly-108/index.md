# 进展速记

## 本期假设 / 预期

**预期：**

进行优化检查，如果没啥问题，下期就准备发布 demo 了

**结果：**

今天之中有一天因为更新开发的 Rimworld 失误而通宵了，结果只来得及检查上次的优化，并将剩下的一点优化收尾，新的优化没来得及跑完……不过新的优化没有机制变更，风险不大。

所以下期进发布阶段！下期构建 release 包后，用 release 包在虚拟机里边录宣传视频边完整试玩（避免出现因为我系统上有开发环境而没发现的问题），然后把挑些截图就能琢磨上 itch 了。steam 的周期有些长，我想还是先在 itch 发免费试玩 demo 页，然后看看开个 patron 之类的——之后的剧情开发就可以铺开了，每一方都有一堆可写的。我想用便宜的会费提供方向投票+独占开发中的更新也许是可接受的方案，但细节我还得再想想。

### 变更：

- 通知系统优化
  - 将下载通知等没有详细内容的自动生成通知改成点击后打开对应文件等动作，避免下载成功之类的提示也让玩家因为怕丢信息而反复点开通知详情
  - 将通知分为重要和非重要通知，避免挤占通知管理器的列表空间
  - 最近 12 个重要通知会进存档持久化，非常重要、之后还会引用的通知会被额外备份进轻聊聊天记录，以免被滚动清掉
- 优化了解码器的表现
- 支线任务完成的后效将会延时生效，避免刚完成就收到联络
- 优化了之前一个有点粗制滥造的支线任务
- 优化了被入侵时的演出效果，添加了音效
- 优化了 demo 结束提示的位置，避免了玩家刚完成任务就一个 demo end 拍脸上导致情绪不连贯。
